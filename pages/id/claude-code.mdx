# Claude Code

Jalankan coding agent **Claude Code** lewat akses Nexotao dan bayar pakai Rupiah.
Cukup arahkan Claude Code ke base URL Nexotao dan pakai API key-mu — tanpa kartu
kredit luar negeri.

<Callout type="info">
  Baru bikin API key di dashboard? Dialog "Kunci berhasil dibuat" sudah langsung
  menampilkan perintah setup dengan key-mu terisi. Halaman ini untuk setup ulang
  atau di komputer lain.
</Callout>

## 1. Install Claude Code

Lewati kalau `claude` sudah terpasang.

**Windows** — buka **PowerShell** (bukan Command Prompt). Claude Code di Windows
butuh [Git for Windows](https://git-scm.com/downloads/win); install dulu kalau
belum ada.

```powershell
irm https://claude.ai/install.ps1 | iex
```

**macOS / Linux**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

## 2. Simpan config Nexotao

Tempel API key, pilih sistem operasi, lalu salin perintah pertama ke terminal.
Perintah itu membuat folder `.claude`, mencadangkan `settings.json` lama (kalau
ada) ke `settings.json.bak`, dan menulis config baru. Tidak perlu membuka atau
mengedit file apa pun.

<ClaudeCodeGenerator />

<Callout type="warning">
  **Masih pakai saldo trial?** Pilih "Masih saldo trial" di generator. Saldo trial
  hanya bisa dipakai model tertentu; kalau config menunjuk model Claude, setiap
  request ditolak dengan `billing.trial_model_restricted` sampai kamu top up.
</Callout>

## 3. Jalankan

Buka terminal **baru** di folder proyekmu lalu jalankan:

```bash
claude
```

## Isi config

| Variabel | Isi |
|---|---|
| `ANTHROPIC_BASE_URL` | `https://api.nexotao.com` (tanpa `/v1`) |
| `ANTHROPIC_AUTH_TOKEN` | API key `sk-nexo-...` milikmu |
| `ANTHROPIC_MODEL` | Model utama. Default generator: Sonnet terbaru di katalog |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` / `_SONNET_` / `_HAIKU_` | Model untuk tiap alias Claude Code. Haiku dipakai untuk background task |
| `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` | `1`, agar kompatibel |

Semua slot model harus menunjuk model yang bisa dipakai key-mu. Kalau hanya
`ANTHROPIC_MODEL` yang diganti, background task tetap memanggil model Haiku.

## Kalau ada masalah

- **`claude` tidak dikenal** — tutup lalu buka lagi terminalnya setelah install.
- **Error 401** — API key salah atau sudah dicabut. Buat key baru di dashboard lalu
  jalankan lagi perintah langkah 2.
- **Error 403 `billing.trial_model_restricted`** — config menunjuk model di luar
  saldo trial. Jalankan ulang generator dengan "Masih saldo trial", atau top up.
- **Mau kembali ke config lama** — salin `settings.json.bak` menjadi `settings.json`
  di folder yang sama.

Biaya pemakaian Claude Code dipotong dari saldo Rupiah, sama seperti panggilan teks
biasa. Lihat [Penagihan & Harga](/penagihan).
