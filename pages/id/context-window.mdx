# Context Window & Kompaksi

Context window mencakup percakapan, balasan model, output tool, dan file yang
dibaca agent. Baca nilai produksi; jangan berasumsi semua model punya 200K token:

```bash
curl -s https://api.nexotao.com/models | jq -r \
  '.models[] | [.model, .context_window] | @tsv'
```

## Setup Claude Code

Pakai ID Claude aktif agar Claude Code bisa mengkalibrasi dan melakukan
kompaksi dengan benar:

| Setting | Nilai |
| --- | --- |
| `ANTHROPIC_BASE_URL` | `https://api.nexotao.com` |
| `ANTHROPIC_AUTH_TOKEN` | key `sk-nexo-...` milikmu |
| `ANTHROPIC_MODEL` | `claude-opus-4-6` |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | `claude-opus-4-6` |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | `claude-sonnet-4-6` |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | `claude-haiku-4-5` |
| `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` | `1` |

Lihat [Claude Code](/claude-code) untuk generator config.

## Menjaga sesi panjang

- Biarkan client autocompact saat mendekati window yang dipublikasikan.
- Jalankan `/compact` sebelum tugas besar atau setelah membaca banyak file.
- Jalankan `/clear` saat tugas selesai dan riwayat tidak lagi diperlukan.
- Untuk client tanpa kompaksi, pangkas atau ringkas giliran lama sendiri.

Kalau prompt terlalu besar, gateway mengembalikan `400
upstream.context_length_exceeded`; lakukan kompaksi, ringkas, atau pecah input.
`413 request.too_large` berarti body HTTP melewati batas gateway.
