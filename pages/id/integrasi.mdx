# Integrasi

Nexotao bukan model baru yang harus kamu pelajari dari nol. Nexotao adalah **gerbang
(gateway)** ke model AI yang sudah kamu pakai — Claude, Qwen, Nova, DeepSeek, dan lainnya — hanya
saja **base URL** dan **API key**-nya diganti ke Nexotao, dan tagihannya dipotong dari
saldo Rupiah.

Tool yang mendukung OpenAI Chat Completions atau Anthropic Messages bisa terhubung
ke Nexotao. Tool yang mewajibkan protokol lain, seperti Codex dengan Responses API,
tidak otomatis kompatibel.

## Dua "mode" — cukup ingat ini

Semua integrasi turun ke salah satu dari dua mode. Kalau kamu paham ini, kamu bisa
menyambungkan tool apa pun, bahkan yang tidak ada di daftar bawah.

| Mode | Base URL | Header / env | Model | Dipakai untuk |
| ---- | -------- | ------------ | ----- | ------------- |
| **Anthropic-compat** | `https://api.nexotao.com` | `x-api-key` / `ANTHROPIC_AUTH_TOKEN` + `ANTHROPIC_BASE_URL` | Semua 32 model Fase 1 | Tool berformat Anthropic Messages, termasuk Claude Code |
| **OpenAI-compat** | `https://api.nexotao.com/v1` | `Authorization: Bearer` / `OPENAI_API_KEY` + `OPENAI_BASE_URL` | Semua 32 model Fase 1 | Tool berformat OpenAI Chat Completions, termasuk Aider dan Continue |

<Callout type="warning">
  **Aturan cepat base URL** — ini penyebab kegagalan integrasi paling sering. Tool
  OpenAI-compat butuh akhiran `/v1` (`https://api.nexotao.com/v1`) dan menambahkan
  `/chat/completions` sendiri. Tool Anthropic-compat pakai host polos
  (`https://api.nexotao.com`) dan menambahkan `/v1/messages` sendiri. Field API key
  selalu diisi apa adanya: `sk-nexo-...`.
</Callout>

## Belum punya API key?

<Steps>

### Daftar

Buat akun di [nexotao.com](https://nexotao.com) — cukup email.

### Top-up saldo

Isi saldo lewat QRIS mulai Rp 10.000.

### Buat API key

Buat key `sk-nexo-...` di menu **API Keys**.

</Steps>

Detail ada di [Quickstart](/quickstart) dan [Autentikasi](/autentikasi).

## Model yang tersedia

Lihat daftar & tarif live di [Model & Harga](/model-harga). Ringkas:

- **Contoh agentic:** `claude-opus-4-6`, `qwen3-coder-next`, `nova-micro`, `gpt-oss-120b`.
- **Contoh chat-only:** `deepseek-v3-2`, `gpt-oss-20b`. Jangan pakai untuk client yang mewajibkan tools.
