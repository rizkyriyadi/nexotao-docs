# Quickstart

Dari nol sampai jalan dalam beberapa menit.

<Steps>

### Daftar

Buat akun gratis di [nexotao.com](https://nexotao.com). Cukup email dan kata sandi.

### Top-up saldo

Isi saldo Rupiah mulai Rp 10.000 lewat **QRIS** atau **crypto (USDT / USDC)**. Saldo
tidak kedaluwarsa dan dipotong per token sesuai pemakaian — tanpa langganan. Isi
Rp 150.000+ dapat bonus saldo **+6%**, Rp 500.000+ dapat **+15%**.

### Buat API key

Di dashboard, buka **API Keys** lalu buat key baru. Bentuknya `sk-nexo-...`.

<Callout type="warning">
  Key hanya ditampilkan penuh **sekali**. Simpan baik-baik saat itu juga — kalau
  hilang, kamu harus mencabutnya dan membuat key baru.
</Callout>

### Request pertama

<Callout type="info">
  **Mau coba tanpa ngoding dulu?** Buka [Playground](/playground) — tempel key,
  pilih model, kirim. Belum paham istilahnya? Baca [Konsep Dasar](/konsep).
</Callout>

Cara paling mudah: endpoint **OpenAI** (`/v1/chat/completions`) — bekerja untuk
**semua model, termasuk Claude**. Bingung memilih? Lihat [Endpoint & Format](/endpoint).

<Tabs items={["Python (OpenAI)", "curl (Anthropic)", "Node.js (OpenAI)"]}>
  <Tabs.Tab>

Format OpenAI (`/v1/chat/completions`) — semua model:

```python
from openai import OpenAI

client = OpenAI(base_url="https://api.nexotao.com/v1", api_key="sk-nexo-...")

resp = client.chat.completions.create(
    model="qwen3-coder-next",  # atau claude-opus-4-6, nova-micro, dst.
    messages=[{"role": "user", "content": "Halo"}],
)
print(resp.choices[0].message.content)
```

  </Tabs.Tab>
  <Tabs.Tab>

Format Anthropic (`/v1/messages`) — semua model Fase 1:

```bash
curl https://api.nexotao.com/v1/messages \
  -H "x-api-key: sk-nexo-..." \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-4-6",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Halo"}]
  }'
```

  </Tabs.Tab>
  <Tabs.Tab>

Node.js (format OpenAI):

```javascript
import OpenAI from "openai"

const client = new OpenAI({ baseURL: "https://api.nexotao.com/v1", apiKey: "sk-nexo-..." })

const resp = await client.chat.completions.create({
  model: "nova-micro",
  messages: [{ role: "user", content: "Halo" }],
})
console.log(resp.choices[0].message.content)
```

  </Tabs.Tab>
</Tabs>

Setiap respons menyertakan header `X-Cost-Rp` (biaya aktual dalam Rupiah) dan
`X-Request-Id`. Lihat [Penagihan & Harga](/penagihan) untuk detail.

### Ganti model cukup ubah satu string

Panggilan yang sama, lebih murah atau lebih kuat — cukup ubah `model`:

- `claude-opus-4-6` — reasoning flagship, vision, tools, dan konteks 1 juta token.
- `qwen3-coder-next` — coding agentic dengan konteks 256 ribu token.
- `nova-micro` — model agentic dengan harga paling rendah di katalog Fase 1.
- `deepseek-v3-2` atau `gpt-oss-20b` — chat-only; jangan dipakai di client yang
  mewajibkan tool calling.

<Callout type="warning">
  Model ID bersifat **case-sensitive** — salin persis dari `GET /models`.
</Callout>

Lihat semua model dan harga hari ini di
[nexotao.com/harga](https://www.nexotao.com/harga).

</Steps>
