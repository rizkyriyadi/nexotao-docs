# OpenAI Codex CLI

OpenAI Codex CLI memakai **Responses API** (`/v1/responses`). Nexotao mendukung
Codex melalui `gpt-5.6-terra` dan `gpt-5.6-luna`; 32 model Bedrock tetap memakai
`/v1/messages` atau `/v1/chat/completions`.

Simpan API key sebagai environment variable:

```bash
export NEXOTAO_API_KEY="sk-nexo-..."
```

Lalu tambahkan provider Nexotao ke `~/.codex/config.toml`:

```toml
model = "gpt-5.6-terra"
model_provider = "nexotao"
model_reasoning_effort = "none"

[model_providers.nexotao]
name = "Nexotao"
base_url = "https://api.nexotao.com/v1"
env_key = "NEXOTAO_API_KEY"
wire_api = "responses"
```

Pakai `gpt-5.6-terra` untuk kualitas coding yang lebih tinggi atau ganti ke
`gpt-5.6-luna` untuk pekerjaan cepat dan ringan. Jangan tempel API key langsung
ke file konfigurasi; `env_key` membuat Codex membacanya dari environment.
