# OpenAI Codex CLI

OpenAI Codex CLI memakai **Responses API** (`/v1/responses`). Saat ini 32 model
Bedrock Fase 1 Nexotao mendukung `/v1/messages` dan
`/v1/chat/completions`, tetapi belum mendukung `/v1/responses`.

Karena itu Codex CLI **belum didukung di Fase 1**. Mengubah
`~/.codex/config.toml` saja tidak akan membuatnya jalan; request saat ini
mengembalikan `model not available on this endpoint`.

Untuk pengalaman coding agentic sekarang, pakai:

- [Claude Code](/claude-code) dengan `claude-opus-4-6`,
  `claude-sonnet-4-6`, atau `claude-haiku-4-5`.
- [Agent terminal](/terminal-agents) yang mendukung OpenAI Chat Completions,
  dengan `qwen3-coder-next`, `qwen3-coder-30b`, atau model lain yang memiliki
  `supports_tools: true` di katalog.

Dukungan Codex baru bisa diaktifkan setelah adapter Responses Nexotao mendukung
model Bedrock secara end-to-end. Cek halaman ini lagi sebelum mengubah
konfigurasi Codex lokalmu.
