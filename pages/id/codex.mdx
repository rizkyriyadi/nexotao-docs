# OpenAI Codex CLI

OpenAI Codex CLI memakai **Responses API** (`/v1/responses`). Di Nexotao, endpoint
ini melayani model keluarga GPT-5.6 (`gpt-5.6-terra`, `gpt-5.6-sol`,
`gpt-5.6-luna`). Model lain tetap dipakai lewat `/v1/messages` atau
`/v1/chat/completions`.

<Callout type="info">
  Baru bikin API key di dashboard? Dialog "Kunci berhasil dibuat" sudah langsung
  menampilkan perintah setup Codex dengan key-mu terisi.
</Callout>

## 1. Install Codex CLI

Codex CLI butuh [Node.js LTS](https://nodejs.org). Kalau perintah `npm` tidak
dikenal, install Node.js dulu lalu buka terminal baru.

```bash
npm install -g @openai/codex
```

## 2. Simpan API key dan config

Ganti `sk-nexo-...` dengan API key milikmu. Perintah ini menyimpan key sebagai
environment variable, mencadangkan `config.toml` lama (kalau ada) ke
`config.toml.bak`, lalu menulis config Nexotao.

<Tabs items={["Windows (PowerShell)", "macOS / Linux"]}>
<Tabs.Tab>

Buka **PowerShell** (bukan Command Prompt), lalu tempel:

```powershell
setx NEXOTAO_API_KEY "sk-nexo-..." | Out-Null
$env:NEXOTAO_API_KEY = "sk-nexo-..."

$dir = Join-Path $env:USERPROFILE ".codex"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
$file = Join-Path $dir "config.toml"
if (Test-Path $file) { Copy-Item $file "$file.bak" -Force }
$body = @'
model = "gpt-5.6-terra"
model_provider = "nexotao"
model_reasoning_effort = "none"

[model_providers.nexotao]
name = "Nexotao"
base_url = "https://api.nexotao.com/v1"
env_key = "NEXOTAO_API_KEY"
wire_api = "responses"
'@
[System.IO.File]::WriteAllText($file, $body)
Write-Host "Config Nexotao tersimpan di $file"
```

</Tabs.Tab>
<Tabs.Tab>

```bash
RC="$HOME/.$(basename "$SHELL")rc"
echo 'export NEXOTAO_API_KEY="sk-nexo-..."' >> "$RC"
export NEXOTAO_API_KEY="sk-nexo-..."

mkdir -p ~/.codex
[ -f ~/.codex/config.toml ] && cp ~/.codex/config.toml ~/.codex/config.toml.bak
cat > ~/.codex/config.toml <<'EOF'
model = "gpt-5.6-terra"
model_provider = "nexotao"
model_reasoning_effort = "none"

[model_providers.nexotao]
name = "Nexotao"
base_url = "https://api.nexotao.com/v1"
env_key = "NEXOTAO_API_KEY"
wire_api = "responses"
EOF
echo "Config Nexotao tersimpan di ~/.codex/config.toml"
```

<Callout type="warning">
  **Masih pakai saldo trial?** Ganti `gpt-5.6-terra` menjadi `gpt-5.6-luna` di
  perintah di atas. Saldo trial hanya bisa dipakai model tertentu; model lain
  ditolak dengan `billing.trial_model_restricted` sampai kamu top up.
</Callout>

## 3. Jalankan

Buka terminal **baru** di folder proyekmu lalu jalankan:

```bash
codex
```

Pakai `gpt-5.6-terra` untuk kualitas coding yang lebih tinggi atau `gpt-5.6-luna`
untuk pekerjaan cepat dan ringan — ganti baris `model` di `config.toml`. Jangan
tempel API key langsung ke file konfigurasi; `env_key` membuat Codex membacanya
dari environment.

## Kalau ada masalah

- **`npm` atau `codex` tidak dikenal** — install Node.js LTS, lalu tutup dan buka
  lagi terminalnya.
- **Codex minta login ke akun OpenAI** — pastikan `model_provider = "nexotao"` ada
  di `config.toml` dan terminal dibuka setelah `NEXOTAO_API_KEY` disimpan.
- **Error 401** — API key salah atau sudah dicabut; jalankan lagi langkah 2 dengan
  key baru.
- **Error 403 `billing.trial_model_restricted`** — ganti model ke `gpt-5.6-luna`
  atau top up.
