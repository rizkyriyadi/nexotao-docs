# Endpoint & Format

Katalog Fase 1 berisi 32 model Bedrock dan dua model GPT-5.6 melalui Azure.
Pilih endpoint berdasarkan model dan format client-mu.

| Format client | Endpoint | Base URL SDK | Autentikasi |
| --- | --- | --- | --- |
| OpenAI Chat Completions | `/v1/chat/completions` | `https://api.nexotao.com/v1` | `Authorization: Bearer sk-nexo-...` |
| Anthropic Messages | `/v1/messages` | `https://api.nexotao.com` | `x-api-key: sk-nexo-...` |
| OpenAI Responses | `/v1/responses` | `https://api.nexotao.com/v1` | `Authorization: Bearer sk-nexo-...` |

`/v1/chat/completions` menerima seluruh 34 model. `/v1/messages` menerima 32
model Bedrock. `/v1/responses` tersedia khusus untuk `gpt-5.6-terra` dan
`gpt-5.6-luna`, termasuk untuk OpenAI Codex CLI.

## Format OpenAI

Pakai untuk OpenAI SDK, Aider, Continue, dan client yang meminta OpenAI base URL:

```python
from openai import OpenAI

client = OpenAI(base_url="https://api.nexotao.com/v1", api_key="sk-nexo-...")

response = client.chat.completions.create(
    model="qwen3-coder-next",
    messages=[
        {"role": "system", "content": "Kamu asisten yang ringkas."},
        {"role": "user", "content": "Jelaskan consistent hashing."},
    ],
)
print(response.choices[0].message.content)
```

## Format Anthropic

Pakai untuk Anthropic SDK dan Claude Code. Endpoint yang sama juga menerima
model Fase 1 non-Claude; misalnya `qwen3-coder-next` sudah divalidasi end-to-end
melalui `/v1/messages`.

```python
from anthropic import Anthropic

client = Anthropic(base_url="https://api.nexotao.com", api_key="sk-nexo-...")

message = client.messages.create(
    model="claude-opus-4-6",
    max_tokens=256,
    system="Kamu asisten yang ringkas.",
    messages=[{"role": "user", "content": "Jelaskan consistent hashing."}],
)
print(message.content[0].text)
```

Dalam format Messages, `system` adalah field level atas dan `max_tokens` wajib.
Jangan tempel body OpenAI ke `/v1/messages`; pakai `/v1/chat/completions`.

Model ID bersifat case-sensitive. Salin dari `GET /models`, dan cek
`supports_tools` sebelum memilih model untuk agent loop.
