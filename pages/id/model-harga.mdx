# Model & Harga

Fase 1 memiliki **34 model aktif** dari 12 provider model: 32 model Amazon
Bedrock serta GPT-5.6 Terra dan Luna melalui Azure. Semua memakai satu key
Nexotao dan satu saldo Rupiah.

## Kebijakan harga

Harga retail Nexotao adalah **snapshot manual** sebesar **100% harga Standard
upstream masing-masing**, dikonversi dengan kurs **Rp 18.000/USD**. Acuannya
AWS Bedrock US Standard untuk 32 model Bedrock dan Azure/OpenAI Standard untuk
GPT-5.6 Terra serta Luna; harga tidak tersinkron otomatis.

Katalog produksi adalah sumber kebenaran. Baca langsung sebelum membuat asumsi
biaya:

```bash
curl -s https://api.nexotao.com/models | jq '.models[] | {
  model, display_name, provider, supports_tools, supports_vision,
  context_window, input_per_million_micro, output_per_million_micro
}'
```
