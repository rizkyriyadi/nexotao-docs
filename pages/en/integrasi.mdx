# Integrations

Nexotao is not a new model you have to learn from scratch. It's a **gateway** to the
AI models you already use — Claude, Qwen, Nova, DeepSeek, and more — except the **base URL** and
**API key** point to Nexotao, and usage is billed from a Rupiah balance.

Tools that support OpenAI Chat Completions or Anthropic Messages can connect to
Nexotao. Tools that require another protocol, such as Codex with the Responses
API, are not automatically compatible.

## Two "modes" — this is all you need to remember

Every integration reduces to one of two modes. Once you understand this, you can wire
up any tool, even ones not listed below.

| Mode | Base URL | Header / env | Model | Used for |
| ---- | -------- | ------------ | ----- | -------- |
| **Anthropic-compatible** | `https://api.nexotao.com` | `x-api-key` / `ANTHROPIC_AUTH_TOKEN` + `ANTHROPIC_BASE_URL` | All 32 Phase 1 models | Tools that speak Anthropic Messages, including Claude Code |
| **OpenAI-compatible** | `https://api.nexotao.com/v1` | `Authorization: Bearer` / `OPENAI_API_KEY` + `OPENAI_BASE_URL` | All 32 Phase 1 models | Tools that speak OpenAI Chat Completions, including Aider and Continue |

<Callout type="warning">
  **Base-URL rule of thumb** — this is the single most common cause of a failed
  integration. OpenAI-compat tools want the `/v1` suffix
  (`https://api.nexotao.com/v1`) and append `/chat/completions` themselves.
  Anthropic-compat tools want the bare host (`https://api.nexotao.com`) and append
  `/v1/messages` themselves. The API key field always takes the raw `sk-nexo-...`
  string.
</Callout>
