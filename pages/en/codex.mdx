# OpenAI Codex CLI

OpenAI Codex CLI uses the **Responses API** (`/v1/responses`). Nexotao's 32
Bedrock Phase 1 models currently support `/v1/messages` and
`/v1/chat/completions`, but not `/v1/responses`.

Therefore Codex CLI is **not supported in Phase 1**. Changing only
`~/.codex/config.toml` will not make it work; requests currently return `model
not available on this endpoint`.

For an agentic coding experience today, use:

- [Claude Code](/en/claude-code) with `claude-opus-4-6`,
  `claude-sonnet-4-6`, or `claude-haiku-4-5`.
- [Terminal agents](/en/terminal-agents) that support OpenAI Chat Completions,
  with `qwen3-coder-next`, `qwen3-coder-30b`, or another model whose catalog
  entry has `supports_tools: true`.

Codex support can be enabled only after the Nexotao Responses adapter supports
Bedrock models end to end. Check this page again before changing your local
Codex configuration.
