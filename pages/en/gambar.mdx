# Image Generation — retired

<Callout type="error">
  The `/v1/images/generations` endpoint is **no longer served**. Any code still
  calling it will fail — remove it or move to another provider.
</Callout>

Image generation has been **retired** from Nexotao. The catalog is now text-only —
[Claude, GPT, DeepSeek, and Grok](/en/model-harga).

See the [Changelog](/en/changelog) for the full catalog change, or go to
[Text & Chat](/en/teks) to make a request against the current catalog.
