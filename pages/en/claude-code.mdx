# Claude Code

Run the **Claude Code** coding agent through Nexotao access and pay in Rupiah. Just
point Claude Code at the Nexotao base URL and use your API key — no foreign credit
card.

<Callout type="info">
  Just created an API key in the dashboard? The "Key created" dialog already shows
  setup commands with your key filled in. This page is for setting up again or on
  another computer.
</Callout>

## 1. Install Claude Code

Skip this if `claude` is already installed.

**Windows** — open **PowerShell** (not Command Prompt). Claude Code on Windows
needs [Git for Windows](https://git-scm.com/downloads/win); install it first if
you don't have it.

```powershell
irm https://claude.ai/install.ps1 | iex
```

**macOS / Linux**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

## 2. Save the Nexotao config

Paste your API key, pick your operating system, then copy the first command into
your terminal. It creates the `.claude` folder, backs up an existing
`settings.json` to `settings.json.bak`, and writes the new config. No file to open
or edit.

<ClaudeCodeGenerator />

<Callout type="warning">
  **Still on the trial balance?** Choose "Still on the trial balance" in the
  generator. The trial balance only works with specific models; if the config
  points at a Claude model, every request is refused with
  `billing.trial_model_restricted` until you top up.
</Callout>

## 3. Run it

Open a **new** terminal in your project folder and run:

```bash
claude
```

## What the config contains

| Variable | Value |
|---|---|
| `ANTHROPIC_BASE_URL` | `https://api.nexotao.com` (no `/v1`) |
| `ANTHROPIC_AUTH_TOKEN` | Your `sk-nexo-...` API key |
| `ANTHROPIC_MODEL` | Primary model. Generator default: the newest Sonnet in the catalog |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` / `_SONNET_` / `_HAIKU_` | Model behind each Claude Code alias. Haiku runs background tasks |
| `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` | `1`, for compatibility |

Every model slot must point at a model your key can use. If you only change
`ANTHROPIC_MODEL`, background tasks still call the Haiku model.

## Troubleshooting

- **`claude` is not recognized** — close and reopen the terminal after installing.
- **Error 401** — the API key is wrong or revoked. Create a new key in the
  dashboard and run the step 2 command again.
- **Error 403 `billing.trial_model_restricted`** — the config points at a model
  outside the trial balance. Rerun the generator with "Still on the trial balance",
  or top up.
- **Want your old config back** — copy `settings.json.bak` over `settings.json` in
  the same folder.

Claude Code usage is deducted from your Rupiah balance, just like a regular text
call. See [Billing & Pricing](/en/penagihan).
